# passvault

Passvault is under active development. The API is subject to change, and a working MVP is not yet available. The target for a feature-complete release is February 1.

The planned result is a local password manager with encrypted vault files and a reusable C++ core for managing named secrets. A command-line interface, terminal UI, and Python API will provide access to the same core, with support for adding, retrieving, and removing secrets.
